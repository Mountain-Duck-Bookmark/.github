## Mountain Duck Highlights

- **Bookmark:** Mountain Duck bookmark stores the address, the sign-in, and the name of a server you are allowed to use.
- **Mounted Disk:** Mountain Duck mounted disk shows that server in the file browser like other disks.
- **SFTP Volume:** Mountain Duck sftp volume is the protected file session many class and office hosts expect.
- **Smart Sync:** Mountain Duck smart sync keeps selected files available while leaving the rest on the server until you open them.
- **File Browse:** Mountain Duck file browse is the ordinary act of opening folders and picking a document.

---

## What Is Mountain Duck

Mountain Duck connects servers and cloud storage as disks, with bookmarks you reuse. Mountain Duck bookmark remembers a host so you do not retype it before every study session. Mountain Duck mounted disk is what you see afterward. A small project, a course drop folder, or a home server you run yourself can live there.

Mountain Duck sftp volume is the common secure path to a host that offers file transfer. Mountain Duck smart sync helps when you want a few files ready on the laptop and the rest left remote. Mountain Duck file browse stays familiar: folders, names, and open. Connect only to machines and accounts you are permitted to use.

Save one Mountain Duck bookmark, open Mountain Duck mounted disk, and try Mountain Duck file browse on a single folder. If the host is SFTP, that disk is Mountain Duck sftp volume. Turn on Mountain Duck smart sync for the subdirectory you actually edit this week.

## Starting with Mountain Duck

Prerequisites: A compatible computer, server details you are allowed to use, and permission to run Mountain Duck.

1. **Prepare:** Copy the host name and your account before you create Mountain Duck bookmark.
2. **Mount It:** Open Mountain Duck mounted disk and wait until the root folder appears.
3. **Browse:** Use Mountain Duck file browse to find one known directory.
4. **Prefer SFTP:** Choose Mountain Duck sftp volume when the host offers that protected path.
5. **Pin A Folder:** Enable Mountain Duck smart sync only for the project you will edit.
6. **Reconnect Later:** Open the same Mountain Duck bookmark next time instead of building a new one.
